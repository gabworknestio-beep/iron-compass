# Security policy

IronPath processes RuneLite account state locally and has no backend. Security-sensitive changes therefore include unexpected network activity, privacy leaks, unsafe file or process access, dependency compromise, and behaviour that could violate Jagex or RuneLite rules.

For a suspected vulnerability, use the repository's private **Security → Report a vulnerability** flow after the public repository is created. Do not publish account-sensitive details or a working exploit in a public issue. Ordinary bugs and incorrect route or gear recommendations can use the normal issue tracker.

Only the latest published Plugin Hub revision is supported with security fixes. Plugin Hub users receive an update after RuneLite accepts the new manifest commit.
